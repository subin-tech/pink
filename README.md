# MelodifyAI

짧은 악기 연주의 음표 추출과 조 변환을 목표로 개발 중인 Python 라이브러리입니다.

> 개발 중인 프로젝트입니다. 음원 채보, 조 변환과 MusicXML 저장은 아직 구현되지 않았습니다.

## 1. What it does

MelodifyAI는 악기를 배우는 학생과 취미 연주자가 짧은 연주를 채보하고 원하는 음높이로 바꾸는 작업을 돕는 것을 목표로 합니다. 현재는 음표 정보 검증만 구현되어 있으며, 아래 음원 처리와 악보 생성 기능은 개발 계획입니다.

### 핵심 기능과 처리 순서

1. **음원 입력 및 검증:** 사용자가 제공하는 30초 이내의 단일 악기 모노 WAV 파일을 읽고 입력 조건을 확인합니다. 원본 파일은 변경하지 않습니다.
2. **음표 추출:** 연주에서 음의 높이와 시작·종료 시간을 추정합니다. 단음뿐 아니라 한 악기에서 동시에 연주된 화음도 지원하는 것을 목표로 합니다.
3. **음표와 반음 값 검증:** 음표의 MIDI 음높이와 시간을 확인하고, 조 변환에 사용할 반음 이동 값이 올바른지 검사합니다. 현재는 음표 검증만 구현되어 있습니다.
4. **조 변환:** 모든 음표를 사용자가 지정한 반음 수만큼 이동합니다. 예를 들어 도·미·솔 화음을 두 반음 올리면 레·파♯·라가 됩니다. 이 기능은 음원에서 원래 조를 자동 판별하는 기능과 구분됩니다.
5. **악보 생성과 저장:** 변환된 음표를 템포에 맞춰 8분음표 단위로 정리하고 MusicXML 파일로 저장합니다. 생성한 파일은 악보 편집기에서 열어 확인할 수 있도록 할 계획입니다.
6. **샘플 웹:** 별도 저장소에서 라이브러리를 설치해 호출하고, WAV 업로드·반음 선택·결과 다운로드 흐름을 제공합니다.

### 사용 예시

사용자가 짧은 피아노 연주 파일 `melody.wav`를 입력하고 반음 이동 값으로 `+2`를 선택합니다. 프로그램은 음표를 추정하고 높이를 바꾼 뒤 `melody_transposed.musicxml`로 저장하는 것을 목표로 합니다. 이 흐름은 아직 구현되지 않았습니다.

### 지원 범위와 한계

- 첫 버전은 단일 악기 모노 WAV와 30초 이내의 음원을 대상으로 합니다. 여러 악기가 섞인 음원에서 악기를 분리하는 기능, 영상 링크 입력과 악보 이미지 인식은 범위 밖입니다.
- 녹음 상태와 겹친 음에 따라 채보 오류가 발생할 수 있습니다. 8분음표 단위로 정리할 때 원래 연주 시점과 차이가 생길 수 있으므로 사용자가 결과를 직접 확인해야 합니다.
- macOS와 Windows에서 실행하는 것을 목표로 하며, 실제 지원 버전과 동작 여부는 각각 검증한 뒤 기록합니다.

## 2. Installation

패키징과 TestPyPI 배포를 준비 중입니다. 아직 `pip install`로 설치할 수 없습니다.

현재 구현된 코드를 확인하려면 저장소를 복제한 뒤 프로젝트 폴더에서 아래 Quick start를 실행합니다.

```bash
git clone https://github.com/subin-tech/pink.git
cd pink
```

## 3. Quick start

현재 구현된 `validate_notes()`는 MIDI 음높이와 시작·종료 시간이 유효한지 확인합니다. 아래 명령은 macOS 또는 Linux 터미널에서 저장소 루트를 기준으로 실행합니다.

```bash
PYTHONPATH=src python3 -c "from music_toolkit.core import validate_notes; validate_notes([{'pitch': 60, 'start': 0.0, 'end': 0.5}]); print('유효한 음표입니다')"
```

음원 입력부터 악보 생성까지의 예제는 해당 기능 구현 후 추가합니다.

## 4. Dependencies

현재 구현된 `validate_notes()`는 Python 표준 라이브러리만 사용합니다. 음원 분석과 MusicXML 생성에 사용할 외부 라이브러리는 선정 후 이름과 라이선스를 기록합니다.

## 5. Tests

가상환경을 활성화한 뒤 저장소 루트에서 아래 명령을 실행합니다. 현재 테스트는 정상 음표, 빈 목록, MIDI 음높이 경계와 잘못된 시간을 검증합니다.

```bash
python -m pip install -e . pytest
python -m pytest
```

아래는 앞으로 추가할 테스트입니다.

- [ ] 음원 입력: 정상 모노 WAV, 30초 경계, 초과 길이, 스테레오, 잘못된 형식과 누락된 파일을 확인합니다.
- [ ] 채보: 사용 허가가 있는 단음·화음 샘플에서 추정 음높이와 시작·종료 시간을 기대 결과와 비교합니다. 오류와 한계를 기록합니다.
- [ ] 조 변환: 양수·음수·0반음 이동, 화음, MIDI 음높이 0과 127의 경계, 범위 초과 오류를 확인합니다.
- [ ] 악보 생성·저장: 고정 템포와 8분음표 단위 변환, 겹친 음, 잘못된 입력, 파일 중복을 시험하고 생성한 MusicXML을 악보 편집기에서 엽니다.
- [ ] 통합: WAV 입력부터 MusicXML 저장까지 연결하고 원본 음원이 유지되는지 확인합니다.
- [ ] 환경: Mac과 Windows의 새 환경에서 설치·실행을 확인하고, 두 운영체제에서 자동 테스트를 실행하도록 구성합니다.
