# 프로젝트 제안서: MelodifyAI

## 1. 프로젝트 주제

### 만들고 싶은 프로그램

사용자가 연주한 음원을 음표 정보로 변환하고, 원하는 조에 맞게 음높이를 바꾼 뒤 악보 파일로 저장하는 Python 라이브러리를 개발한다. 별도의 샘플 앱에서는 음원 업로드와 결과 확인 기능을 제공한다.

### 사용자와 문제

악기를 배우는 학생이나 취미 연주자는 직접 들으며 음표를 기록하거나, 연주하기 편한 조로 악보를 옮기는 데 시간이 걸린다. 이 도구는 짧은 연주를 채보하고 조를 바꾸는 작업을 도와준다. 사용자는 결과를 듣거나 악보 편집기에서 열어 잘못 인식된 부분을 확인한다.

## 2. 개발할 기능

### 입력

- 사용자가 제공하는 30초 이내의 단일 악기 모노 WAV 음원
- 조 변환에 사용할 반음 이동 값
- 다른 음원 형식 지원 여부는 별도 시험을 거친 뒤 결정한다.

### 처리

1. 입력 음원과 길이를 확인한다.
2. 음원의 음높이와 시작·종료 시간을 분석해 음표 목록을 만든다.
3. 사용자가 지정한 반음 수만큼 음표의 높이를 이동한다.
4. 변환된 음표 목록을 악보 편집기에서 열 수 있는 MusicXML로 만든다.
5. 결과 파일을 저장하고 샘플 앱에서 확인할 수 있도록 한다.

### 결과

- 변환 전후 음표 정보
- 조 변환 결과를 담은 MusicXML 파일
- 원본 음원은 변경하지 않는다.

### 개발 범위

- 포함: 짧은 단일 악기 음원, 자동 채보, 반음 단위 조 변환, MusicXML 저장, 라이브러리를 사용하는 샘플 앱
- 제외: 영상 링크 입력, 여러 악기의 동시 채보, 악보 이미지 인식, 고급 악보 편집
- 한계: 음질이나 겹쳐 연주된 음에 따라 음표와 리듬이 잘못 인식될 수 있으므로 결과를 직접 확인해야 한다. 박자는 고정 템포를 기준으로 변환하므로 수정이 필요할 수 있다.

### 사용 예시

사용자가 짧은 피아노 연주 파일 `melody.wav`와 반음 이동 값 `2`를 입력한다. 프로그램은 음표를 추출하고 각 음을 두 반음 올려 `melody_transposed.musicxml`로 저장한다. 사용자는 악보 편집기에서 파일을 열어 결과를 확인한다.
